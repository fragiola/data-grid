First release. `@fragiola/data-grid-react` is the React 19 adapter: the unstyled `DataGrid.*` primitives (render the grid as a `<table>`, as `<div>`s or anything else, with `render` to swap an element and state as `data-*` and ARIA), the hooks, `useLocalRows` for rows in memory, every feature's entry point with its hooks, and the whole core re-exported, so a React app installs this one package.
