First release. `@fragiola/data-grid-vue` is the Vue 3.5 adapter: the unstyled `DataGrid.*` primitives (`as` and the `render` slot to swap an element, scoped slots for the collection parts, state as `data-*` and ARIA), `typedDataGrid<TRow, TFeatures>()` for typed templates, the composables, `useLocalRows` for rows in memory, every feature's entry point with its composables, and the whole core re-exported, so a Vue app installs this one package.
