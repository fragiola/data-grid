---
title: State attributes
description: Every state a part has is a data attribute or ARIA, present or absent, so any styling solution can read it.
---

A part's state is on its element, as `data-*` attributes and ARIA. A boolean attribute is
present (empty) or absent, never `"false"`.

## Parts

Every part carries `data-grid-part`: `root`, `grid`, `header`, `header-row`, `header-cell`,
`body`, `row`, `cell`, `row-detail` or `empty`. Rows and cells carry their indexes: `data-row-index` (header
rows are `-1` and above, a header cell spanning rows is at its top one) and `data-column-index`
(a header cell spanning columns is at its first). Tests select by them, never by class names.

## States

| attribute | on | when |
| --- | --- | --- |
| `data-active` | cell, header cell | it is the active cell |
| `data-active` | row | it holds the active cell |
| `data-interacting` | cell, header cell | its controls have the keys ([Controls in cells](/docs/concepts/keyboard#controls-in-cells)) |
| `data-loading` | row, cell | its row is not loaded yet (`getRow` answered `undefined`) |
| `data-empty` | root, grid | the grid has no rows ([Empty state](/docs/guides/empty-state)) |
| `data-group` | header cell | it is a group's ([Column groups](/docs/concepts/column-groups)) |
| `data-expanded` | row | it shows its detail ([Master-detail](/docs/guides/master-detail)) |
| `data-pinned` | cell, header cell | `start`: its column is pinned ([Pinned columns](/docs/concepts/pinned-columns)) |
| `data-pinned-edge` | cell, header cell | it ends at the last pinned column |
| `data-sortable` | header cell | its column is sortable ([Sorting](/docs/concepts/sorting)) |
| `data-sort` | header cell | `ascending` or `descending`, while its column is sorted |
| `data-sort-priority` | header cell | its column's place in the sort, 1-based |

## ARIA

| attribute | on | value |
| --- | --- | --- |
| `role` | grid, rowgroup, row, columnheader, gridcell | the grid pattern |
| `aria-rowcount` | grid | every row, header rows included, rendered or not |
| `aria-colcount` | grid | every column |
| `aria-rowindex` | row | 1-based, the header rows first |
| `aria-colindex` | cell, header cell | 1-based (a group's first column) |
| `aria-colspan` | header cell, row detail | the columns a group spans, when more than one; a detail spans every column |
| `aria-rowspan` | header cell | the header rows a column spans, when more than one |
| `aria-sort` | header cell | the first sorted column's direction |

## Styling a state

```css title="grid.css"
[data-grid-part="cell"][data-active] {
    outline: 2px solid var(--accent);
    outline-offset: -2px;
}

[data-grid-part="row"][data-loading] [data-grid-part="cell"]::after {
    content: "";
    inline-size: 60%;
    block-size: 0.75rem;
    background: var(--placeholder);
}
```

With Tailwind: `data-active:outline-2`, `data-loading:opacity-50`, `in-data-empty:hidden`,
`data-group:justify-center`.
