This page builds the grid of the [`hello-grid`](/examples/hello-grid) example, step by step.

<Steps>

<Step>

## Describe the columns

A column is a plain object, typed by your row. `key` names it (and reads `row[key]` by default),
`name` is the header's text, `width` is in pixels.

<Framework name="react">

```tsx title="columns.ts"
import type { Column } from "@fragiola/data-grid-react";

interface Person {
    id: number;
    name: string;
    email: string;
    salary: number;
}

export const columns: Column<Person>[] = [
    { key: "id", name: "#", width: 64 },
    { key: "name", name: "Name", width: 180 },
    { key: "email", name: "Email", width: 260 },
    {
        key: "salary",
        name: "Salary",
        width: 120,
        renderCell: ({ row }) => `$${row.salary.toLocaleString()}`,
    },
];
```

</Framework>

<Framework name="vue">

```ts title="columns.ts"
import type { Column } from "@fragiola/data-grid-vue";
import type { VNodeChild } from "vue";

export interface Person {
    id: number;
    name: string;
    email: string;
    salary: number;
}

export const columns: Column<Person, VNodeChild>[] = [
    { key: "id", name: "#", width: 64 },
    { key: "name", name: "Name", width: 180 },
    { key: "email", name: "Email", width: 260 },
    {
        key: "salary",
        name: "Salary",
        width: 120,
        renderCell: ({ row }) => `$${row.salary.toLocaleString()}`,
    },
];
```

In Vue a column's renderers return vnodes (`VNodeChild`: a string, or `h("b", row.name)`), so
the column type names it.

</Framework>

<Framework name="angular">

```ts title="columns.ts"
import type { Column, DataGridNode } from "@fragiola/data-grid-angular";

export interface Person {
    id: number;
    name: string;
    email: string;
    salary: number;
}

export const columns: Column<Person, DataGridNode>[] = [
    { key: "id", name: "#", width: 64 },
    { key: "name", name: "Name", width: 180 },
    { key: "email", name: "Email", width: 260 },
    {
        key: "salary",
        name: "Salary",
        width: 120,
        renderCell: ({ row }) => `$${row.salary.toLocaleString()}`,
    },
];
```

In Angular a column's renderers return a `DataGridNode` (text, or a template with its context:
`templateContent(template, props)`), so the column type names it.

</Framework>

</Step>

<Step>

## Render the grid

`Root` takes the data; `Grid`, `Header` and `Body` are the structure. With no children, the header
renders a cell per column and the body a row per row, each with its cells.

<Framework name="react">

```tsx title="people-grid.tsx"
import { DataGrid } from "@fragiola/data-grid-react";

export function PeopleGrid({ people }: { people: Person[] }) {
    return (
        <DataGrid.Root columns={columns} rows={people} rowKey={(row) => row.id} style={{ height: 400 }}>
            <DataGrid.Grid aria-label="People">
                <DataGrid.Header />
                <DataGrid.Body />
            </DataGrid.Grid>
        </DataGrid.Root>
    );
}
```

</Framework>

<Framework name="vue">

```vue title="people-grid.vue"
<script setup lang="ts">
import { typedDataGrid } from "@fragiola/data-grid-vue";
import { columns, type Person } from "./columns";

defineProps<{ people: Person[] }>();

const DataGrid = typedDataGrid<Person>();
</script>

<template>
    <DataGrid.Root :columns="columns" :rows="people" :row-key="(row) => row.id" style="height: 400px">
        <DataGrid.Grid aria-label="People">
            <DataGrid.Header />
            <DataGrid.Body />
        </DataGrid.Grid>
    </DataGrid.Root>
</template>
```

A template cannot pass a type argument, so `typedDataGrid<Person>()` returns the same components
typed by your row: the `row` of `rowKey` and of the slots below is a `Person`.

</Framework>

<Framework name="angular">

The parts are directives on your own elements, and the rows and cells are your templates:
`<ng-template dataGridRows let-row>` repeats for each rendered row. `*dataGridCellContent`
renders a cell's default content (the column's name in the header, its renderer or value in the
body).

```ts title="people-grid.ts"
import { ChangeDetectionStrategy, Component, input } from "@angular/core";
import { DATA_GRID } from "@fragiola/data-grid-angular";
import { columns, type Person } from "./columns";

@Component({
    selector: "app-people-grid",
    imports: [DATA_GRID],
    changeDetection: ChangeDetectionStrategy.OnPush,
    template: `
        <div dataGridRoot [columns]="columns" [rows]="people()" [rowKey]="rowKey" style="height: 400px">
            <div dataGridGrid aria-label="People">
                <div *dataGridHeader>
                    <div dataGridHeaderRow>
                        <ng-template dataGridHeaderCells let-cell>
                            <div [dataGridHeaderCell]="cell"><ng-container *dataGridCellContent /></div>
                        </ng-template>
                    </div>
                </div>
                <div dataGridBody>
                    <ng-template [dataGridRows]="columns" let-row>
                        <div [dataGridRow]="row">
                            <ng-template [dataGridCells]="columns" let-cell>
                                <div [dataGridCell]="cell"><ng-container *dataGridCellContent /></div>
                            </ng-template>
                        </div>
                    </ng-template>
                </div>
            </div>
        </div>
    `,
})
export class PeopleGrid {
    readonly people = input.required<Person[]>();
    readonly columns = columns;
    readonly rowKey = (row: Person) => row.id;
}
```

`[dataGridRows]="columns"` types the template's `row` by your row: it is a `Person`.

</Framework>

It already scrolls, renders only the rows in view, and answers the arrow keys. It has no look:
the next step gives it one.

</Step>

<Step>

## Style the parts

Every part exposes its state as `data-*` attributes. Write the parts out to style each one.

<Framework name="react">

A part takes `className` (a string, or a function of its state).

```tsx title="people-grid.tsx"
<DataGrid.Body>
    <DataGrid.Rows<Person>>
        {(row) => (
            <DataGrid.Row row={row} className="border-b">
                <DataGrid.Cells<Person>>
                    {(cell) => (
                        <DataGrid.Cell cell={cell} className="px-3 data-active:outline-2" />
                    )}
                </DataGrid.Cells>
            </DataGrid.Row>
        )}
    </DataGrid.Rows>
</DataGrid.Body>
```

</Framework>

<Framework name="vue">

A part takes `class` and `style` as attributes, merged under its structural style. The
collection parts take a default scoped slot in place of React's children function.

```vue title="people-grid.vue"
<DataGrid.Body>
    <DataGrid.Rows v-slot="{ row }">
        <DataGrid.Row :row="row" class="border-b">
            <DataGrid.Cells v-slot="{ cell }">
                <DataGrid.Cell :cell="cell" class="px-3 data-active:outline-2" />
            </DataGrid.Cells>
        </DataGrid.Row>
    </DataGrid.Rows>
</DataGrid.Body>
```

</Framework>

<Framework name="angular">

The elements are yours: give them `class` and `style`, merged under their structural style.

```html title="people-grid.ts"
<div dataGridBody>
    <ng-template [dataGridRows]="columns" let-row>
        <div [dataGridRow]="row" class="border-b">
            <ng-template [dataGridCells]="columns" let-cell>
                <div [dataGridCell]="cell" class="px-3 data-active:outline-2">
                    <ng-container *dataGridCellContent />
                </div>
            </ng-template>
        </div>
    </ng-template>
</div>
```

</Framework>

The header needs a background: it stays at the top while the rows scroll under it. Its place
above them is the grid's own (a structural `z-index`); the color is yours.

</Step>

<Step>

## Render it as a table, if you like

`render` swaps the element of any part (in Vue, `as` or the `render` slot:
`<DataGrid.Grid as="table">`; in Angular, the directives go on table elements:
`<table dataGridGrid>`, `<tr [dataGridRow]="row">`), so the same grid can be a real table. See
[Tables or divs](/docs/concepts/tables-or-divs) and the [`table-elements`](/examples/table-elements)
example.

</Step>
