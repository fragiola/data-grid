## Install the package

<Framework name="react">

A React app installs one package, `@fragiola/data-grid-react`: the primitives, the hooks and the
whole framework-agnostic core, re-exported.

```sh title="Terminal"
pnpm add @fragiola/data-grid-react
```

</Framework>

<Framework name="vue">

A Vue app installs one package, `@fragiola/data-grid-vue`: the primitives, the composables and
the whole framework-agnostic core, re-exported.

```sh title="Terminal"
pnpm add @fragiola/data-grid-vue vue
```

</Framework>

<Framework name="angular">

An Angular app installs one package, `@fragiola/data-grid-angular`: the directives, the
injection functions and the whole framework-agnostic core, re-exported.

```sh title="Terminal"
pnpm add @fragiola/data-grid-angular
```

</Framework>

The core, `@fragiola/data-grid`, comes along: import its types and helpers from any of the
packages.

## Features and entry points

The main entry is a small core: it renders, scrolls, virtualizes and answers the keys. The rest
comes from entry points of the same package, imported only when used:

| entry | holds |
| --- | --- |
| `/sorting` | `sorting()`, a [feature](/docs/concepts/features) the grid installs for its columns to sort |
| `/local` | rows in memory, sorted, filtered, grouped and paged ([Rows in memory](/docs/concepts/rows-in-memory)) |
| `/selection` | a "select all" control ([Row selection](/docs/concepts/row-selection)) |

So `@fragiola/data-grid-react/sorting` (or `-vue/sorting`, `-angular/sorting`) needs no other
package. What an app never imports is not in its bundle.

## Peer dependencies

<Framework name="react">

The React package needs React 19 (`react` and `react-dom`). It has no other runtime
dependency, and the core has none at all.

</Framework>

<Framework name="vue">

The Vue package needs Vue 3.5 (`vue` **^3.5**). It has no other runtime dependency, and the core
has none at all. The Vue package renders in the browser only: server rendering is not supported
yet.

</Framework>

<Framework name="angular">

The Angular package needs Angular 22 (`@angular/core` **^22**). It has no other runtime
dependency, and the core has none at all. Its directives are standalone, zoneless and
`OnPush`-safe. The Angular package renders in the browser only: server rendering is not
supported yet.

</Framework>

## No stylesheet

There is nothing to import for styles: the primitives set only the inline style they need to
place things (positions and sizes). Style the parts with your own classes: in React through
`className`, `style` or `render`, in Vue through `class`, `style`, `as` or the `render` slot
([Vue primitives](/docs/api/vue) maps each React prop the other pages show), in Angular on your
own elements, which the directives go on ([Angular directives](/docs/api/angular)). See
[Styling with Tailwind](/docs/guides/styling-tailwind) and
[Styling with plain CSS](/docs/guides/styling-css).

<Callout type="info" title="A size to scroll in">
`DataGrid.Root` (in Angular, the element `dataGridRoot` is on) is the scroll container. Give it a height (and a width, or let it fill its
parent), or it grows with its content and nothing is virtualized. See
[Sizing the grid](/docs/getting-started/sizing).
</Callout>
