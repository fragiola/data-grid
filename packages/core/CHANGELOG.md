# @fragiola/data-grid

## 0.1.0

### Minor Changes

- [#169](https://github.com/fragiola/data-grid/pull/169) [`f7d8901`](https://github.com/fragiola/data-grid/commit/f7d8901a4d8afebffaa4476f24a1c8e8774cc470) Thanks [@maurodesouza](https://github.com/maurodesouza)! - First release. `@fragiola/data-grid` is the framework-agnostic core of a headless data grid built for millions of cells: a typed model whose every change is a command, the axis math, windows and scroll scaling that virtualize both axes past the browser's size limit (rows by array or by index, measured row heights), the engine that binds a grid to the DOM, and the opt-in features, each an entry point: sorting, filtering, search, pagination, keyboard navigation, row selection, cell ranges, the clipboard, the fill handle, cell editing, column resizing, reordering, pinning and collapsible groups, row expansion, grouping and reordering, column spans, summary rows, and `/local` for rows in memory. Zero runtime dependencies.
