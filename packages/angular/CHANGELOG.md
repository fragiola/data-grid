# @fragiola/data-grid-angular

## 0.1.0

### Minor Changes

- [#169](https://github.com/fragiola/data-grid/pull/169) [`f7d8901`](https://github.com/fragiola/data-grid/commit/f7d8901a4d8afebffaa4476f24a1c8e8774cc470) Thanks [@maurodesouza](https://github.com/maurodesouza)! - First release. `@fragiola/data-grid-angular` is the Angular 22 adapter: standalone, signal-based, zoneless attribute directives on your own elements (`DATA_GRID`: `dataGridRoot`, `dataGridGrid`, `dataGridRow`, `dataGridCell`, …), the injection functions, `injectLocalRows` for rows in memory, every feature as a secondary entry point with a root directive for its inputs, and the whole core re-exported, so an Angular app installs this one package. Built by ng-packagr (Angular Package Format, partial compilation, ESM only).
